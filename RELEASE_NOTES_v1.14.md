# AIRTOOLS Android v1.14

Версия приложения: `versionName = 1.14`, `versionCode = 15`.

## Изменения относительно 1.13

- На экране выбранной Wi-Fi сети верхний значок становится стрелкой «Назад» и возвращает к списку всех сетей.
- Системная кнопка Back сначала возвращает из карточки сети к списку; выход выполняется с главного экрана.
- Временное отсутствие дополнительных сведений при обновлении экрана не сбрасывает определённое имя подключённого устройства.
- Список сетей поддерживает протокол ESP32-C6 v0.2.2: `ssid_encoding=hex`, строгую декодировку UTF-8 и текст `SSID 0x...` для непечатных/некорректных имён.
- Сохранена поддержка предыдущего текстового формата `/networks`.
- Библиотека `SHARED-APP/neoui` предоставляет действие навигации через левую иконку панели.

## Совместимость и проверка

- Android SDK 26+.
- Совместим с AIRTOOLS ESP32 v0.2.2 и прежним форматом `/networks`.
- `gradlew.bat :app:assembleDebug --no-daemon` — успешная сборка.

Вложения к релизу содержат патчи исходного кода приложения и общего компонента навигации.
